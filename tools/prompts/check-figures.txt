【本轮：只核对示意图（换一个模型独立核对上一轮新补的 SVG 图）】
本篇（{{id}}）里有几张内联 SVG 示意图，大多是上一轮新补的，还没有人独立看过。只做这一件事：
1. 写一个 node 或 python 脚本，把本篇源文件 data/src/lessons/{{id}}.js 里每个 <svg>…</svg> 依次存成 {{tmp}}/{{id}}-fig1.svg、fig2.svg……，同时打印每张图前后各约 150 字的正文（看图要表达什么）。
2. 对每张图运行 node tools/svg-png.js 图.svg 图.png，再用 Read 打开 PNG 看。
3. 逐张核对：图和旁边的正文、图注说的是不是同一回事；曲线形状、交点、极值点、坐标轴、箭头方向、标注是否正确；有没有文字重叠、压线、出界、标签错位。数学上画错的（例如函数图像形状不对、点的位置和计算结果不符）必须改正；纯排版问题（重叠、出界）顺手修好。
4. 只改图本身（坐标、标签、viewBox），不要改正文，不要加新图，也不要删图（除非图完全错误且无法修正，这时删掉并在 issues 说明）。
最后运行 node tools/check.js lesson {{id}} 直到 ✓。issues 里只写你改了哪张图、改了什么；没问题就写"示意图核对无误"。
