【本轮额外要求：结合 2016–2025 年真题（近十年）】
网站的讲解页会把真题引用变成可点击的链接，读者点开就是题库里那道题。所以这一篇要和近十年真题紧密结合：
1. 找真题：在仓库下运行 grep -n -B7 "'{{id}}'" data/src/years/201[6-9].js data/src/years/202[0-5].js，找出 kp 里含本考点的题（kp 数组第一个是主考点）。需要完整题面时，只读那道题所在的几十行（id、no、stem、options、answer），不要通读整个文件。
2. 新增一节 kind: 'example'，标题「近十年真题精讲」（题多可以拆成两节）：挑 2–4 道最有代表性的（主考点优先，覆盖不同题型与设问方式，近年优先）。每道题：
   - 开头注明出处，写成 <span class="qref" data-q="题目id">2019 年第 9 题</span>（题目 id 就是题库里的 id 字段，例如 2019-9；网页会把它变成链接）。题面忠实照抄题库里的 stem（以及选项），数字、符号、上下限一律不改。
   - 按「这题考什么 → 从题面哪个特征想到用什么方法 → 分步解答（每步说理由）→ 这道题告诉我们什么」讲透，并和本篇前面的定义、定理呼应（指出用到了哪个定理）。
   - 最终答案必须和题库里的 answer 一致；能算的用 sympy 验证。
3. 「考研怎么考」一节（kind: 'exam'）：根据找到的全部近十年真题概括考法——常见题型与分值、设问方式、常和哪些考点综合、近几年的变化。每条结论后面点名对应的真题（同样用 qref 写法）。题库里没有的题一律不许编造；本考点近十年真题很少时如实说明，可以改用更早年份的真题（同样可以引用）。
4. 其他小节照常写（why/def/thm/example/pitfall/method/check），篇幅一般 12000–20000 字。
5. 运行 node tools/check.js lesson {{id}}：它会核对每个 data-q 的 id 是否在题库里，改到 ✓ 为止。
