# 数一高数真题研习

考研数学一 **高等数学** 部分的复习网站：按考试大纲分成 8 章，所有讲解和例题都来自历年真题。

- **72 道真题**（1997–2023），每题有答案、完整解析和易错提醒
- 每章包括 **大纲要求**、**必会工具**（公式和方法）、**真题规律**，以及按考点分组的 **真题精讲**
- 每道题可以标记「会了」或「不会」，「不会」的题会自动进 **错题本**
- **随机刷题**：按章节、题型抽题，可以跳过已掌握的题
- **按年份浏览**：查看某一年收录的全部高数题
- 支持手机和深色模式（深色是黑板配色）

## 怎么打开

**方法一：直接用浏览器打开**
下载本仓库（GitHub 页面上 Code → Download ZIP），解压后双击 `index.html`。需要联网，因为公式渲染（MathJax）和字体要从网上加载。

**方法二：用 GitHub Pages 发布成网址**
仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选这个分支、目录选 `/ (root)`，保存后等一两分钟就能拿到网址。

## 文件结构

```
index.html        页面骨架
css/style.css     样式（浅色 / 深色两套配色）
js/chapters.js    8 章的大纲要求、必会工具、真题规律
js/problems.js    真题题库（题干、选项、答案、解析、易错提醒）
js/app.js         路由、做题标记、错题本、随机刷题
```

## 添加新题

在 `js/problems.js` 的 `PROBLEMS` 数组里加一项即可，页面会自动统计题量、年份和章节进度：

```js
{
  id: '2024-lim',          // 唯一 id
  ch: 'lim',               // 章节：lim diff int vec mdiff mint series ode
  topic: '未定式极限',      // 考点，同一章内相同考点会分到一组
  year: 2024,
  type: '填空',             // 选择 / 填空 / 解答
  stem: R`题干，公式写成 $...$ 或 $$...$$`,
  options: [ ... ],         // 选择题才需要，4 项
  answer: R`答案`,          // 选择题写字母，如 'C'
  solution: R`<p>解析</p>`,
  tip: R`易错提醒（可选）`,
  note: '备注（可选）'
}
```

## 说明

- 题目按年份整理自历年全国硕士研究生招生考试数学一试卷的高等数学部分，题干措辞可能与原卷略有出入；少数选择题为方便练习改成了直接求解，页面上已注明。
- 所有答案都用计算机代数系统（SymPy）复核过。建议对照官方原卷使用。
- 做题标记只保存在当前浏览器（localStorage），换设备或清除浏览器数据后不会保留。
